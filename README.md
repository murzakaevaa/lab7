# Lab 7. Docker basics (П07)

## Что было сделано
1. Установлен Docker (`docker.io`).
2. Пользователь добавлен в группу `docker` для работы без `sudo`.
3. Создана структура проекта: папка `nginx/` с `dockerfile`, `index.html` и `nginx-conf/nginx.conf`.
4. Написан `Dockerfile` на базе официального образа `nginx`, который копирует HTML-страницу и конфиг внутрь образа.
5. Собран Docker-образ с тегом `devops/nginx-server`.
6. Написан скрипт `deploy.sh`, который автоматически пересоздает контейнер и запускает его с пробросом порта `54321:80`.
7. Проверена работа веб-сервера через `curl` и в браузере.

## Файлы в репозитории
- `deploy.sh` — скрипт автоматической сборки и запуска контейнера.
- `nginx/dockerfile` — инструкция для сборки образа.
- `nginx/index.html` — статическая страница с приветствием.
- `nginx/nginx-conf/nginx.conf` — конфигурация веб-сервера Nginx.
